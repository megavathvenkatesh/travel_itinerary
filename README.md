# 🌍 Travel Itinerary Application

A full-stack web app for planning, saving, and retrieving personalized travel itineraries using AI and real-time travel APIs.

---

## 🛠️ Built With

- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MongoDB (with Mongoose)
- **APIs Used:**
  - Google Maps Autocomplete API
  - Google Generative AI API
  - Flight and Hotel APIs (Real-time)
  - IATA Code Retrieval API

---

## ✨ Features

- **🗺️ Google Autocomplete**  
  Get instant location suggestions as you type your destination.

- **🤖 AI-Powered Suggestions**  
  Personalized travel plans generated using Google Generative AI API.

- **✈️ Flight & Hotel Integration**  
  Real-time data on flights and hotels based on user-selected locations and dates.

- **📦 IATA Code Auto-Fetching**  
  Seamless integration of flight search with automatic IATA code mapping.

- **💾 Save & Retrieve Itineraries**  
  Save travel plans to MongoDB and view them later through your dashboard.
